## 💻 Sobre o Projeto

O **Blog Selibi** é uma aplicação front-end criada como projeto escolar para homenagear a escritora brasileira Thalita Rebouças. O site apresenta uma navegação fluida (*smooth scroll*) por diversas seções que documentam a carreira da autora, suas principais coleções literárias e o impacto de suas obras no cinema.

O projeto se destaca pelo design moderno e responsivo, utilizando animações CSS puras para criar um carrossel infinito de livros e efeitos visuais imersivos nos cards (como o *backdrop-filter* para revelar sinopses).

---

## ⚙️ Funcionalidades

- **Carrossel Animado:** Exibição dinâmica em loop infinito das capas dos livros usando `@keyframes`.
- **Linha do Tempo Interativa:** Uma jornada cronológica detalhando os marcos da carreira da autora.
- **Efeitos de Hover (Blur):** Cards de livros que revelam o título e a sinopse suavemente ao passar o mouse.
- **Cinema em Grid:** Seção dedicada aos pôsteres de filmes organizados de forma totalmente responsiva (`auto-fit`).
- **Navegação Âncora:** Menu fixo no topo que direciona o usuário suavemente para cada seção do site.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica em blocos (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** 
  - Layouts construídos com **Flexbox** e **CSS Grid**.
  - Estilização de componentes e efeitos visuais avançados (`box-shadow`, `backdrop-filter`, `transform`).
  - Animações contínuas e transições suaves (`transition: 0.3s ease`).
